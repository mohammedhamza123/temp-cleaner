# برنامج منظف الملفات المؤقتة (Windows Temp Cleaner)

🧹 برنامج بسيط لحذف ملفات النظام المؤقتة في ويندوز بضغطة زر واحدة، باستخدام Python و Tkinter.

## ⚙️ المميزات:
- واجهة بسيطة وسهلة الاستخدام
- تنظيف ملفات TEMP بضغطة واحدة
- شعار مخصص 

## 📥 التحميل:
[اضغط هنا لتحميل النسخة EXE](https://github.com/mohammedhamza123/temp-cleaner/releases)

## 🧠 طريقة الاستخدام:
1. حمّل الملف `main.exe`
2. شغّله مباشرة (بدون الحاجة لتثبيت Python)
3. اضغط "نظف الآن" وانتظر الرسالة

## 🛠️ التطوير:
تم بناء البرنامج باستخدام:
- Python
- Tkinter
- PIL
- PyInstaller

## طريقة تشغيل البرنامج على ويندوز

عند فتح البرنامج لأول مرة، قد تظهر لك رسالة من Windows تقول:

> Windows protected your PC  
> Microsoft Defender SmartScreen prevented an unrecognized app from starting.

لا تقلق، هذا طبيعي لأن البرنامج جديد ولم يتم التعرف عليه بعد.

لتشغيله:

1. اضغط على **More info** (معلومات إضافية).
2. اضغط على **Run anyway** (تشغيل على أي حال).

البرنامج آمن 100%، وتم تطويره بلغة Python لتنظيف ملفات النظام المؤقتة فقط.
